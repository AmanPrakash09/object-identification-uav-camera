# RGB Dataset
To get the dataset, go to https://github.com/VisDrone/VisDrone-Dataset.

Download the `trainset`, `valset`, and `testset-dev` drives in "Task 1: Object Detection in Images."

From there, organize the data like this:
```
visdrone-dataset-rgb/
├── train/
│   ├── images/
│   └── annotations/
├── val/
│   ├── images/
│   └── annotations/
└── test-dev/
    ├── images/
    └── annotations/
```

# Infrared Dataset
To get the dataset, go to https://github.com/VisDrone/DroneVehicle.

Download the `Train`, `Validation`, and `Test` datasets. You will have to translate the page to English, download an installer, create an account, and then download the data.

From there, organize the data like this:
```
visdrone-dataset-infrared/
├── train/
│   ├── images/
│   └── annotations/
├── val/
│   ├── images/
│   └── annotations/
└── test-dev/
    ├── images/
    └── annotations/
```
